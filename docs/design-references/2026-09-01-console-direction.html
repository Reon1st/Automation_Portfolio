Type

Display (human moments): Georgia / serif, restrained, large — headline & name only.
Body: system sans, neutral, does the reading work.
Utility/data: Consolas / monospace — every status label, count, timestamp, platform tag.

Layout

Split hero: left pane = the human (photo, serif headline, CTA). Right pane = the machine — a live status table pulling real per-platform automation counts. A single hairline vertical rule separates them.

Signature

The status panel is not decoration — it's the actual proof, sourced from real data, shown before any scroll. Literalizes "you get a dashboard, not a black box" as the first thing a visitor sees.
